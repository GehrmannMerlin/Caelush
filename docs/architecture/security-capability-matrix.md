# V1 Security Capability Matrix — Phase 9D

The matrix distinguishes what is enforced by code, what is guarded by policy/approval, and what is deliberately not isolated in V1.

| Surface                                                                                             | Capability                             | State                         | Boundary                                                                                                                       |
| --------------------------------------------------------------------------------------------------- | -------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `read_file`, `list_directory`, `find_files`, `search_text`, `apply_patch`, `git_status`, `git_diff` | Workspace-relative structured access   | **ENFORCED**                  | Lexical and realpath containment, schema validation, bounded IO, symlink checks where applicable                               |
| `exec_command`, `write_stdin`                                                                       | Local shell/process execution          | **POLICY / APPROVAL GUARDED** | Security Facts, command policy, runtime-kind admission, durable Gate/Approval, sanitized child environment                     |
| All built-ins                                                                                       | Required capabilities and runtime kind | **ENFORCED**                  | Definition metadata, logical sandbox admission, default security-facts coverage audit                                          |
| `rg`                                                                                                | Search helper                          | **ENFORCED**                  | Fixed executable/args, `--no-config`, sanitized helper environment, `shell:false`, bounded output                              |
| Git read helpers                                                                                    | Status/diff helper                     | **ENFORCED**                  | Fixed read-only args, no prompts, pager/config hardening, `--no-ext-diff`, `--no-textconv`, fsmonitor disabled, bounded output |
| Sensitive Context resources                                                                         | File inclusion                         | **ENFORCED**                  | Shared Security classifier before content read; `.env.example`/`.env.sample`/`.env.template` exceptions                        |
| Project-derived Context text                                                                        | Model projection                       | **ENFORCED**                  | High-confidence redaction of instructions, relevant files, and project metadata                                                |
| Tool result and approval preview                                                                    | Public/model/event projection          | **ENFORCED**                  | Sanitize before persistence/projection; previews contain only redacted safe facts                                              |
| Cached approval                                                                                     | Authorization                          | **POLICY / APPROVAL GUARDED** | Current Gate decision precedes exact same-Run grant lookup; missing durable approval infra fails closed                        |
| Host environment                                                                                    | Child compatibility variables          | **ENFORCED**                  | Runtime-owned platform-aware allowlist; credential/injection/config variables removed                                          |
| Parent process memory and private durable ToolInvocation args                                       | Secret erasure                         | **NOT ISOLATED**              | V1 does not encrypt arguments at rest or claim secrets never exist in SQLite/memory                                            |
| Shell child syscall/filesystem/network/process identity                                             | OS isolation                           | **NOT ISOLATED**              | `UNCONFINED_LOCAL_PROCESS`; no seccomp, container, job object, ACL, or network sandbox                                         |
| Remote runtime, MCP, Browser, cancellation, timeout, retry, budget, Verification                    | Future host capabilities               | **NOT ISOLATED**              | Explicitly outside Phase 9D and reserved for later phases                                                                      |

`STRUCTURED_WORKSPACE` is a logical admission label, not an operating-system sandbox. `UNCONFINED_LOCAL_PROCESS` is an explicit honesty label for the local shell/process boundary.
